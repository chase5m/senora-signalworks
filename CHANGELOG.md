# Changelog

## 0.3.11 — Free source release

Based on the authoritative 0.3.10 runtime. Gameplay handlers, events, callbacks, state keys, SQL behavior, accepted hand grip/flags 33 and streamed binaries are preserved.

- Added the user-approved Chase Free Source License: free use/modification and same-term free sharing; no resale or rebranding.
- Moved advanced configuration into `config/` and introduced a concise common `config.lua` loaded last.
- Changed public installation defaults to automatic framework/key selection and debug off. Other values remain equivalent.
- Removed authored code comments outside configuration. Kept creator attribution in manifest/documentation and preserved dependency license notices separately.
- Included readable React/TypeScript source, locked dependencies and a reproducible build that writes readable runtime JavaScript to `web/`.
- Replaced historical installation guidance with all four SQL migrations, protocol-3 voice bridge instructions and current dashboard/receiver behavior.
- Added current verification scope and Discord support information.

This package has not been installed over the running development server. Cleanup and packaging checks are not a new claim of native acceptance on every framework or multiplayer setup.
